# Controls

Most things are interactable in the header and footer. Try tapping on them!

Button names below are the Xbox-style letters. With `Controller Layout` set to
Switch, X and Y swap places (as they do on the pads themselves) and the footer
prints the other letter - the action is the same either way.

There are four layouts, switched via the "Display Mode" setting (List by default).

## Collection Screen *(Display Mode: List)*
|controller|touch|action|
|----------|-----|------|
|`left/right`|`swipe left/right`|navigate forward/backward in the list|
|`L1/R1`||previous or next collection|
|`A button`|`tap collection`|switch to games list|
|`B button`||pegasus settings menu|
|`Y button`|`tap header icon`|retromega settings menu|
||`tap clock`|12/24 hour clock|
|`R2`|`tap footer icon`|open search|
|`L2`|`tap footer icon`|attract mode|

## Game List with sidebar *(Display Mode: Sidebar)*
The Collection Screen is replaced by a sidebar on the left inside the Game List. It starts out focused so you can browse consoles; press right/A to move into the games column.

|controller|touch|action|
|----------|-----|------|
|`up/down` *(sidebar focused)*|`tap`|highlight a console (Arcade, Game Boy, etc); preview updates live|
|`up/down` *(games focused)*|`tap`|select a game, tap twice to launch|
||`swipe up/down`|scroll list|
|`left`|`swipe right`|return focus to the sidebar (from the games column)|
|`right`|`tap collection`|move focus into the games column (from the sidebar)|
|`A button`|`tap`|move into games column (sidebar) / launch game (games column)|
|`B button`|`tap footer icon`|back to sidebar (from games column); bubbles to Pegasus' menu from the sidebar|
|`X button`|`tap footer icon`|mark game as favorite (games column only)|
|`Y button`|`tap header icon`|retromega settings menu (sidebar) / cycle thumbnail art, tap footer icon (games column)|
|`R1/L1`||previous/next console (sidebar) / skip to previous or next letter (games column)|
|`R2`|`tap footer icon`|open search|
|`L2`|`tap footer icon`|attract mode (sidebar) / game details screen, long press game (games column)|

## Settings
A single scrolling list. Every setting is grouped under a section heading, and the platform collections sit at the bottom under "Reorder".

|controller|touch|action|
|----------|-----|------|
|`up/down`|`tap`|highlight a setting or platform (section headings are skipped)|
||`swipe up/down`|scroll list|
|`A button`|`tap`|toggle setting, cycle to the next option for multi-choice settings like Font Size, or open the Platforms panel|
|`left/right`||step a multi-choice setting (Display Mode, Cards Size, Font Size, Theme, Controller Layout, Cycle Art Types) to the previous/next option|
|`right`|`tap`|open the Platforms panel (from the Platforms row)|
|`B, X, or Y button`|`tap footer icon`|back to the Collection Screen|
||`tap settings icon`|back to the Collection Screen|

### Platforms panel *(Reorder → Platforms)*
Slides in from the right; the settings list behind it is dimmed and keeps its place.

|controller|touch|action|
|----------|-----|------|
|`up/down`|`tap`|highlight a platform, or move the grabbed one up/down|
|`A button`|`tap a highlighted row`|grab the highlighted platform, or drop (save) an already-grabbed one|
||`tap ▲/▼ on a row`|move that platform one place and save immediately|
|`B button` `left`|`tap outside the panel`|drop a grabbed platform (if any), otherwise close the panel|

---

## Search (RT/ZR)
RT/ZR - now shown as a "Search" button in the footer, beside Attract (Collection Screen) or Details (Game List) - opens the Name Filter box directly. The old Sorting and Filters list screen has been removed entirely; sorting by title/rating/release/favorite and the Only Favorites/Only Multiplayer toggles are no longer available.

|controller|touch|action|
|----------|-----|------|
|`A button`|`keyboard enter`|apply the search (shown as "Search" in the footer)|
|`B button`|`tap outside modal window`|discard name filter changes|
|`X button`|`tap footer icon`|clear name filter|
